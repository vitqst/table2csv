# Table to CSV Exporter

A Chrome extension to convert HTML tables to CSV.

## Features

- Detects HTML tables on a webpage.
- Converts tables to CSV format.
- Allows copying the data or downloading it as a file.

## How to Use

1. Install the extension.
2. Open a webpage with an HTML table.
3. Click the extension icon in the Chrome toolbar.
4. The extension will detect the tables and display them in the popup.
5. You can then copy the CSV data or download it as a file.
